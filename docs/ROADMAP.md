# Roadmap

Ideas and priorities — open an issue to discuss or vote with 👍.

## 0.2 — Polish
- [ ] Window previews (DWM thumbnails) when hovering Dock icons.
- [ ] Drag to reorder icons directly in the Dock.
- [ ] Hide the island and Dock automatically for full-screen apps and games.
- [ ] Replace the Windows volume/brightness OSD with the island.
- [ ] Brightness activity (WMI / DDC-CI).
- [ ] Bluetooth device connected/battery activity (AirPods-style).

## 0.3 — Platform
- [ ] **Signed MSIX / sparse package** for package identity → notifications in the island, Start-up task API, cleaner updates.
- [ ] `winget` manifest.
- [ ] Multi-monitor: Dock and menu bar per display, island on the active display.
- [ ] Real background blur behind the Dock (DesktopAcrylicController on a shaped child window).

## 0.4 — Extensibility
- [ ] Plugin SDK (see [PLUGINS.md](PLUGINS.md)): custom island activities and Dock items.
- [ ] Calendar module (next meeting countdown).
- [ ] Clipboard / AirDrop-like file shelf in the expanded island.

## Later
- [ ] More languages (contributions welcome — see CONTRIBUTING).
- [ ] Themes marketplace.
